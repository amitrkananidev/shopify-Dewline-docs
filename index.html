Set up Dewline. Glow different.

Dewline is a Shopify Online Store 2.0 theme for beauty and skincare brands. It includes a mega menu, ingredient-led product pages, a skin quiz, routine and bundle builders, a magnifier zoom, a wishlist, quick view and more. Everything is set up in the theme editor, with no code.

1. Setup in 15 minutes

1
Install. Online Store → Themes → add Dewline from the Theme Store (or upload the zip). Use Customize to preview, and Publish when you're ready.
2
Logo & colours. Customize → Header → Logo. Then Theme settings (gear icon) → Colours and Typography.
3
Menus. Content → Menus. Build Main menu with nested items, then add a Mega menu block in the Header for each top-level item that should open a panel (see §4).
4
Pages. Content → Pages → Add page, and choose the matching template — About, Contact, FAQ, Ingredients, Skin quiz, Routines, Store locator or Wishlist (see §5).
5
Product details. Create the dewline metafield definitions (see §8) so key ingredients, skin types and how-to-use content appear on product pages.
6
Filters. Install the free Shopify Search & Discovery app and switch on the filters you want. Dewline shows them on collection and search pages automatically.
7
Homepage. Customize → Home page. Click each section to pick collections, products and images. Sections show tasteful placeholders until you do.
8
Discount codes. If you use the bundle builder, countdown or newsletter popup, create the matching discount codes in Discounts (see §11).

Adding a mega menu

  1. Customize → Header → Add block → Mega menu.
  2. Type the top-level item's title exactly in Menu item (e.g. Skincare).
  3. Choose a layout: Columns (links with collection thumbnails) or Grid (round image tiles — great for skin concerns).
  4. Optional: pick a collection to feature up to 4 products, and add up to 2 promo cards (image, heading, link). Portrait images (4:5) look best.

Items with children but no mega block open a compact dropdown. On phones the menu becomes a slide-in drawer with a screen per section, thumbnails, and the first promo card.

The account icon uses Shopify's account component: signed-out shoppers get one-tap sign-in, signed-in customers see their initial and an account menu. Pick its menu in Header → Customer account menu.

7. Product page

The product information section is built from blocks you can add, reorder or remove: Text · Title · Rating · Price · Skin type & step · Variant picker · Stock status · Buy buttons · Shade / size guide · Complementary products · Beauty badges · Free-from list · Key ingredients · Description · Collapsible tab · Share · Custom Liquid · app blocks.

Zoom

On desktop, hovering the image shows a magnifier glass (strength 2×–4× in the section settings). Clicking the image, or the zoom button on phones, opens full-screen zoom.

Shades & variants

Options named Shade, Colour or Color show as swatches. Variant images switch the gallery. The Shade / size guide block opens a popup with your own content and image.

Subscriptions

Install a selling-plan app (e.g. Shopify Subscriptions). Plans appear above the buttons with the saving shown, and in the cart.

Pickup, installments, gift cards

Local pickup availability shows per variant when pickup is enabled in Settings → Shipping. Shop Pay Installments appear under the price when enabled in Settings → Payments. Gift card products get a "send as a gift" recipient form.

Share

Round icons for WhatsApp, Facebook, X, Pinterest, email and copy link; phones also get the native share sheet. Turn networks on or off in the Share block.

Reviews

Install any reviews app and add its app block. Star ratings on cards and in Google results use the standard reviews.rating metafields that review apps fill in.

9. Collections, search & filters

Collection and search pages share the same filter panel — a sidebar on desktop or a drawer (your choice), plus active-filter chips and sorting. Filters update without reloading the page. Swatch filters show colours or images.

Pagination can be page numbers, a Load more button, or infinite scroll. The search page groups pages and articles under the product results.

Predictive search shows products, collections and pages as you type, with trending searches before typing.

10. Cart

Choose a slide-out drawer (default) or a cart page in Theme settings → Cart. Both show line and order discounts, unit prices, subscription details, quantity rules and order notes.

  • Free-shipping bar — set the threshold in your store currency.
  • Upsell — pick a collection; products already in the cart are skipped.
  • Gift wrap & message — pick a gift-wrap product to offer it as a checkbox.
  • Express checkout — Shop Pay, Apple Pay, PayPal and other wallets show on the cart page (and optionally in the drawer).

11. Quiz, bundles & promos

  • Skin quiz — add Question blocks and write one answer per line as Answer label|result-key (e.g. Tight and flaky|dry). Then add a Result block for each key with a title, text and recommended collection. The result picked most often wins.
  • Bundle builder — set items per bundle and the discount shown, then create the matching discount code in Discounts (e.g. 15% off, minimum 3 items) and enter it in the section. It's applied automatically at checkout.
  • Countdown — set the end date and time and an optional code shoppers can tap to copy.
  • Newsletter popup — choose delay and frequency; the code is revealed after signup. Create the code in Discounts.
  • Cookie banner & age gate — the cookie banner uses Shopify's Customer Privacy API; the age gate is optional.

FAQ

Products don't show on the homepage

Click the section and choose a collection. Make sure products are Active and published to the Online Store sales channel.

The mega menu doesn't open

Add a Mega menu block in Header and type the menu item's title exactly as it appears in Content → Menus. The item also needs child links.

Key ingredients or skin types aren't showing

Create the metafield definitions in §8 with namespace dewline, then fill them on each product.

The filter button shows nothing

Install Shopify Search & Discovery and turn on at least one filter. Filters appear within a minute.

The bundle or popup discount isn't applied at checkout

The theme only displays the code. Create the code with the same name in Discounts, and check its minimum quantity and dates.

How do I make a word in a heading pink and italic?

Wrap it in asterisks: Glow *different*.

Can I use my own fonts?

Pick any font from Shopify's font library in Theme settings → Typography. Custom font files aren't supported in Theme Store themes.

Where is the wishlist saved?

In the shopper's browser, so no account is needed. It shows on the Wishlist page and as a counter in the header.

Checkout doesn't match my theme colours

Checkout is hosted by Shopify. Match colours, fonts and logo in Settings → Checkout → Customize.

How do I get updates?

When a new version is released, an Update button appears in Online Store → Themes. Your settings and content are kept.
